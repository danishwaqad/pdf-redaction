## Redact PDF on Android — browser workflow

| Requirement | Detail |

| Android | 8.0+ recommended |
| PDF source | Files, Gmail attachment, Drive download |

### Step-by-step

| Step | Action |
|------|--------|
| 1 | Open **Chrome** (not in-app browser inside Facebook/WhatsApp) |
| 2 | Go to [RedactPDF](/tool) |
| 3 | Tap upload → pick PDF from Files or Downloads |
| 4 | Use mobile tabs: **PDF**, **Search**, **PII** |
| 5 | Draw boxes with finger; pinch-zoom for precision |
| 6 | Tap **Apply Redactions** → download to Downloads |
| 7 | Open redacted file → search for known sensitive strings |

### Mobile layout tips

| Tip | Why |

| Rotate to landscape | Wider canvas for box drawing |
