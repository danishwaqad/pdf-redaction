## Quick answer

**Redacted** means sensitive information was **removed** before the document was shared — not just covered up. **Redaction** is the process; **to redact** is the action. In PDFs, a properly **redacted** file should fail **Ctrl+F** searches for deleted strings and should not paste removed text into Notepad.

If you searched **redacted**, **redaction**, **redact**, or **redacting** because you need to clean a PDF — this page explains the terms and points you to a **free** tool that performs **permanent** removal.

## Redacted vs blacked out — the difference that matters

| Term | What users think | What actually happened |
|------|------------------|------------------------|
| Redacted | Text is gone | Text deleted from PDF structure ✓ |
| Blacked out | Text is hidden | May still be searchable ✗ |
| Edited | File changed | Could mean anything — verify |

News articles say a document was **"heavily redacted"** when blocks hide classified lines. In court, a **redacted exhibit** must not leak privileged text. The standard is **content destruction**, not ink color.

## What is redaction in practice?

**Redacting** a PDF typically means:

1. Identify sensitive strings (names, SSNs, account numbers, privileged paragraphs)
2. Mark regions to remove
3. **Apply** redaction so extractable content is deleted
4. **Verify** the output before distribution

**Redacting** is not drawing a rectangle in Word and exporting to PDF. That often creates a **redacted-looking** file that still fails compliance review.
