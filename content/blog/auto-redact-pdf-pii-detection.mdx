Automation helps — if you understand what it catches, what it misses, and how to verify the export. This guide covers PII detection in [RedactPDF](/tool), a safe workflow, and limits you must plan for.

## What auto redaction means in practice

True auto redaction in one click without review does not exist for regulated workflows. Responsible auto redaction means:

1. **Detect** candidate sensitive strings (patterns + search)
2. **Review** every mark on every page
3. **Add manual boxes** for what patterns miss
4. **Apply** permanent redaction
5. **Verify** the downloaded PDF

Skip step 2 or 5 and you inherit liability.

## Auto redact workflow step by step

| Step | Action |
|------|--------|
| 1 | Upload PDF to [RedactPDF](/tool) |
| 2 | Run PII pattern detection — review counts before accepting |
| 3 | Run custom search for names, matter IDs, codenames |
| 4 | Manual page-by-page review (headers, footers, tables) |
| 5 | Apply redactions → download → verify with search |

Auto-detect will not catch person names, unstructured addresses, internal codenames, or usernames without `@`. Search for known strings and mark all matches.

## Auto redact vs manual-only

| Approach | Best for |
|----------|----------|
| Auto PII detect | Logs, exports, discovery with many emails/phones |
| Text search | Repeated entity names, case numbers |
| Manual boxes | Signatures, faces in images, one-off phrases |
| Combined | Real productions and compliance packets |

## OCR and auto redact on scanned PDFs

Scanned pages have no text until OCR runs. Use the **Run OCR** banner in RedactPDF, wait for completion, then run PII detect. Without OCR, auto redact finds nothing on image-only pages.

## False positives and false negatives

| Type | Example | What to do |
|------|---------|------------|
| False positive | Box on innocent numeric string | Delete or shrink mark before apply |
| False negative | Missed person name or note | Add manual box — review every page |
| OCR miss (scans) | Word not in text layer | Run OCR first or box image region |
