Scanned PDFs — paper scans, fax exports, phone photos saved as PDF — look like normal documents but often have **no selectable text**. You cannot search, auto-detect PII, or redact strings that the file does not know exist. This guide explains OCR-first redaction in [RedactPDF](/tool), hybrid PDF pitfalls, and verification for image-heavy pages.

## Scanned PDF vs digital PDF

| Type | Text selectable? | Redaction approach |
|------|------------------|------------------|
| Born-digital PDF | Usually yes | Search, PII detect, boxes |
| Scan / photo PDF | No until OCR | OCR → mark → apply |
| Hybrid (Canva, exports) | Mixed | Per-page strategy |

If drawing boxes is disabled with a message about OCR, your page is image-dominant.

## Step 1 — Run OCR in RedactPDF

| Step | Action |
|------|--------|
| 1 | Open [RedactPDF](/tool) and upload the scan |
| 2 | Go to a page without text — banner prompts **Run OCR** |
| 3 | Wait for progress (recognition engine loads from CDN; internet required) |
| 4 | Confirm search and text highlights work when marking |

OCR adds a text layer aligned to visible words. Quality depends on scan resolution, skew, and handwriting (handwriting OCR is limited).

## Step 2 — Mark sensitive content

After OCR:

- **PII auto-detect** for emails, phones, cards, SSN patterns
- **Search** for names and case-specific strings OCR recognized correctly
- **Manual boxes** over signatures, stamps, faces, or OCR misses

Zoom in on low-confidence regions. Garbled OCR may need larger boxes covering entire lines.

## Step 3 — Apply permanent redaction

Apply redactions as with digital PDFs. On hybrid pages, consider **Secure page** mode if the entire page background is sensitive (flattens to image for maximum assurance on marked hybrid pages).

## Step 4 — Verify scanned redactions

| Failure mode | What went wrong | Prevention |
|--------------|-----------------|------------|
| OCR miss | Sensitive word never detected | Visual read at 100% zoom; manual boxes |
| Cosmetic redaction | Pixels still show under small box | Cover full line or image region |
| Hybrid layer leak | OCR text survives under image box | Rasterize page or use secure page mode |

| Verification test | Pass criteria |
|-------------------|---------------|
| Visual scan | No readable PII at 100% zoom |
| Search (Ctrl+F) | Known strings return zero hits |
| Copy-paste | Text layer omits redacted content |

For image-only redaction without reliable OCR, mark the **image region** with boxes covering the full sensitive area.

## Poor scan quality tips

| Issue | Fix |
|-------|-----|
| Blurry text | Re-scan at 300 DPI |
| Skewed pages | Deskew before upload |
| Mixed digital + scan | Split into separate files |
| Handwriting | Manual image boxes (OCR limited) |
