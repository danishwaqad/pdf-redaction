Visa officers, mortgage underwriters, and landlords ask for **bank statement PDFs** — then applicants panic about exposing account numbers, large transactions, or unrelated income. **Redact bank statement PDF** searches spike before immigration seasons and loan deadlines. This guide shows how to **hide account number PDF** fields permanently while keeping the document credible for reviewers.

> **Disclaimer:** Embassy and lender rules vary by country and product. Confirm what must remain visible before redacting. This guide is not immigration or financial advice.

## What to redact on bank statements

| Field | Usually redact? | Notes |
|-------|-----------------|-------|
| Full account number | Yes | Leave last 4 digits only if required |
| Routing / sort code | Often yes | Check recipient requirements |
| Credit card numbers | Yes | Full 16 digits |
| Unrelated transactions | Often yes | Gambling, transfers unrelated to application |
| Balance on other accounts | Case by case | Show required proof of funds only |
| Name / address | Rarely | Needed for identity match |
| Salary deposits | Usually keep | Proof of income |

## Wrong ways applicants redact statements

| Method | Problem |
|--------|---------|
| White box in phone photo app | Not a real PDF workflow |
| Edge draw tool | Text still searchable |
| Cover with sticker in Canva | Export leaves extractable layer |
| Crop screenshot | Loses official formatting — may be rejected |

Use [permanent redaction](/blog/how-to-remove-text-from-pdf-permanently) instead.

### White-out vs black-out on statements

Many applicants prefer [white out appearance](/blog/how-to-white-out-text-in-pdf) for cleaner pages. Security is identical — underlying text must be **deleted**.
