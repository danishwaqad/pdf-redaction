## Quick answer

On Windows, **do not use Microsoft Edge markup** to hide Social Security numbers, account data, or client names. Edge draws on top of the PDF; the text usually remains searchable. For **free PDF redaction on Windows 11/10 without installing software**, use a browser-based redactor such as [RedactPDF](/tool), then verify with Ctrl+F before you email or file anything.

## What actually happens on Windows

Most Windows users double-click a PDF and it opens in **Edge**. For reading, perfect. For confidentiality, dangerous — because pen tools and black shapes feel like redaction but rarely delete the underlying text layer. The same pattern breaks on Mac Preview; we cover that in [redact PDF on Mac](/blog/redact-pdf-mac).

A paralegal on Windows 10 described the usual story: she blacked out account numbers in Edge for a visa support packet, sent the PDF, and the recipient recovered the numbers with search. The fix was not "draw darker boxes" — it was re-processing the file in a tool that **removes** text and then running the three tests in [why blacking out is not safe](/blog/why-blacking-out-pdf-is-not-safe).

## Microsoft Edge: what works and what does not

Edge is excellent for viewing, signing in some workflows, and light annotation. It is **not** a redaction engine.

If you draw a filled rectangle over a line of text, you add new drawing instructions on top of the old ones. Press **Ctrl+F** and search for the hidden string. If Edge finds it, you have an overlay — not redaction. Paste the whole document into Notepad and you will often see the same failure.

Other Windows shortcuts fail for the same reason:

- **Paint / Snipping Tool** — you are making a new image, not sanitizing the original PDF structure
- **Word** — black rectangle then Save as PDF often exports text still extractable underneath
- **"Print to PDF"** after highlighting — does not reliably delete sensitive strings

### Large PDFs on Windows (honest limits)

We tested a **4 MB text PDF with roughly 1,294 pages** — search and mark-all can run in seconds, but opening that many pages in a browser tab can exhaust RAM on a typical laptop. Edge may show "This page is having a problem" (tab crash). Mitigations:

- Close other tabs before upload
- Use desktop Chrome or Edge on a machine with **8 GB+ RAM**
- Split the PDF into 200-page chunks for marking, then merge redacted outputs if your workflow allows
- See [batch redact workflow](/blog/how-to-batch-redact-pdf) for repeatable firm processes

Files up to **100 MB** are supported in the uploader; page count and text density matter more than megabytes for browser stability.

### Verification on Windows

Use the same three tests on the downloaded PDF in Edge or Adobe Reader:

1. **Ctrl+F** — zero hits on known PII
2. **Select** across redacted areas — nothing highlights
3. **Copy all → Notepad** — sensitive strings absent
