## HIPAA and PDF redaction — what matters

HIPAA protects **Protected Health Information (PHI)**. De-identified data falls outside HIPAA only when identifiers are removed per regulatory standards — cosmetic blackout often **fails** technical de-identification because text remains extractable.

| Concept | Redaction implication |
|---------|----------------------|
| Minimum necessary | Redact only what recipients do not need |
| De-identification | Permanent removal, not overlays |
| Business associates | Cloud upload tools may need BAA |
| Breach notification | Failed redaction = potential breach |

## PHI identifiers to redact (Safe Harbor overview)

| # | Identifier | PDF location examples |
|---|------------|----------------------|
| 1 | Names | Headers, chart face sheets |
| 2 | Geographic data smaller than state | Patient address blocks |
| 3 | Dates (except year) | DOB, admission dates |
| 4 | Phone / fax | Contact sections |
| 5 | Email | Demographics |
| 6 | SSN | Billing attachments |
| 7 | Medical record numbers | Barcodes, headers |
| 8 | Health plan numbers | Insurance cards scanned |
| 9 | Account numbers | Hospital bills |
| 10–18 | URLs, IPs, biometrics, photos, etc. | Varies by record type |

Always follow organizational policy — Safe Harbor is a framework, not a checkbox.

## Step-by-step: redact medical records PDF

| Step | Action |
|------|--------|
| 1 | Confirm lawful basis for disclosure (treatment, payment, authorization, legal) |
| 2 | Open [RedactPDF](/tool) — document workflow per internal policy |
| 3 | Mark all PHI — manual + PII detect for phones, emails, SSN |
| 4 | Run OCR on scanned chart pages first |
| 5 | Review **every page** including stickers, barcodes, margins |
| 6 | Apply permanent redaction |
| 7 | Independent verification — second reviewer when possible |
| 8 | Log action per audit policy |

## Scanned charts and hybrid PDFs

| Record type | Risk |
|-------------|------|
| EHR export | Hidden text layers |
| Fax scan | OCR text under image |
| Lab report PDF | MRN in barcode — box entire label |
| Photo of wound | Identify patient in image — box region |

## Verification checklist

| Test | Pass |
|------|------|
| Search patient name | Zero hits (if de-identifying) |
| Search MRN / account | Zero hits |
| Search DOB formats | Zero hits |
| Paste to text editor | No PHI strings |
| Visual scan | No faces/identifiers in images unmarked |
