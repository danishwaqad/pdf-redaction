## Quick answer

**Batch redact PDF** today on RedactPDF means **one file per session** — but you can still process a hundred files by Friday if you standardize folders, rules, and a per-file checklist. Run **PII detect** + **search** on every upload, verify each output, log pass/fail. Native zip bulk upload is on the roadmap; this guide is the honest free method until then. Start each file at [RedactPDF](/tool).

## Phase 1 — Prepare once (~30 minutes)

Create `source/` and `redacted/` folders. Write a **redaction rules** doc: what always gets removed (SSN, full account numbers, unrelated transactions — see [bank statement guide](/blog/how-to-redact-bank-statement-pdf)). Naming: `ORIGINAL_v1.pdf` → `REDACTED_v1.pdf`. Bookmark [RedactPDF](/tool). Share [auto redact PII](/blog/auto-redact-pdf-pii-detection) steps with every operator.

## Phase 2 — Per file (~3–8 minutes each)

1. Upload next PDF from `source/`
2. **PII detect** + **search** for matter strings (client name, matter ID)
3. Manual pass: headers, footers, exhibits, scanned pages ([OCR guide](/blog/how-to-redact-scanned-pdf-ocr))
4. **Apply** → save to `redacted/` with certificate
5. **Verify** — search one known string; log pass/fail in a spreadsheet (filename, date, operator)

Never skip verification because "the last forty looked fine." One leak is enough.

## Phase 3 — QA sample (10%)

Randomly open 10% of redacted outputs. Full search + paste test. If any fail, re-audit the operator's session and expand sampling.

## Speed tips without cutting corners

- Same browser tab — avoid re-downloading assets
- Pre-list search terms per matter type
- Split huge PDFs on desktop before mobile attempts
- Court productions: [redact PDF for court](/blog/how-to-redact-pdf-for-court) checklist per file

## When to pay for enterprise tools

Hundreds of files **daily**, Bates numbering, production load files, or privilege logs at scale → Adobe or Relativity-class platforms. Episodic batches of tens or low hundreds → free repeatable workflow + [without Adobe](/blog/how-to-redact-pdf-without-adobe) guide.
