## Why SSN redaction fails so often

| Failure mode | How it happens |
|--------------|----------------|
| Visual blackout only | SSN remains in content stream — searchable |
| Partial redaction | Last four digits left with other identifiers |
| Header/footer repeat | SSN on page 1 only; copies on every page |
| OCR text layer | Image redacted but invisible text survives |
| Metadata | Author field contains SSN in filename path |

## SSN redaction vs pseudonymization

| Approach | SSN handling |
|----------|--------------|
| Redaction | Removed — cannot recover from file |
| Pseudonymization | Replaced with token — mapping held separately |
| Masking (XXX-XX-1234) | May still identify with other data |

Choose per legal requirement — redaction is irreversible.
